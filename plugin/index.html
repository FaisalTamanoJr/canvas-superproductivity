Putting courses in a folder

Plugins cannot create folders, so this step is manual (about once per semester):

  1. In the left sidebar, hover over the Projects heading and click the new folder icon next to it. Name it e.g. "Fall 2026".
  2. Drag each course project into it.
  3. At the end of the semester, archive the course projects. Archived courses stop syncing.
